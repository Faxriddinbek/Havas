Havas Project - Resume uchun ma'lumot
Loyiha tavsifi:
Havas — Django REST Framework asosidagi e-commerce/maishiy mahsulotlar API. Mahsulotlar, savat, story, so'rovnomalar va foydalanuvchi boshqaruvi funksiyalari mavjud.
Ishlatilgan texnologiyalar:
Backend Framework & Core:
Django 5.2.7 — Web framework
Django REST Framework 3.16.1 — REST API
Python 3.12 — Dasturlash tili
Authentication & Security:
Django REST Framework SimpleJWT 5.5.1 — JWT autentifikatsiya
PyJWT 2.10.1 — Token boshqaruvi
Custom authentication backend (email/username/phone_number orqali login)
Database:
PostgreSQL 16 — Relational database
psycopg2-binary — PostgreSQL adapter
Database migrations va indexing
Internationalization:
django-modeltranslation 0.19.17 — Ko'p tillilik (English/Uzbek)
Multi-language support (EN, UZ)
API Documentation:
drf-spectacular 0.28.0 — OpenAPI/Swagger dokumentatsiya
Swagger UI va ReDoc integratsiyasi
Media & File Handling:
Pillow 12.0.0 — Rasm boshqaruvi
Generic media model (rasm, video, hujjatlar)
Media file upload va storage
External Integrations:
pyTelegramBotAPI 4.29.1 — Telegram bot integratsiyasi
Telegram xabarnomalar (xatoliklar uchun alertlar)
Configuration & Environment:
django-environ 0.12.0 — Environment variables boshqaruvi
Configuration management
Containerization & DevOps:
Docker — Containerization
Docker Compose — Multi-container orchestration
Nginx (proxy) — Reverse proxy va static files serving
Alpine Linux — Minimal container images
Testing:
Django test framework
Unit tests (product, user modullari uchun)
Loyiha arxitektura va funksiyalar:
Modullar (Apps):
User Management — Custom user model (email/username/phone_number), JWT auth, device tracking
Product Management — Mahsulotlar CRUD, kategoriyalar, narxlar, chegirmalar
Story Module — Story CRUD, so'rovnomalar (survey), savollar va javoblar
Shopping List — Xarid ro'yxatlari, rangli kategorizatsiya
Shared Module — Umumiy utilitylar, exception handling, middleware, permissions
