# Havas — E-commerce REST API

**Havas** — Django REST Framework asosida qurilgan e-commerce va maishiy mahsulotlar uchun REST API platforma.  
Loyiha mahsulotlar, foydalanuvchilar, xarid ro‘yxatlari, story va so‘rovnomalarni boshqarishni ta’minlaydi.

---

## 🚀 Asosiy imkoniyatlar

- RESTful API arxitektura
- JWT asosidagi autentifikatsiya va avtorizatsiya
- Email / username / phone orqali login
- Ko‘p tillilik (EN / UZ)
- Media fayllar (rasm, video, hujjat) bilan ishlash
- Telegram orqali xatoliklar haqida xabarnoma
- Swagger / OpenAPI dokumentatsiya
- Docker + Nginx orqali production-ready deploy

---

## 🛠 Texnologiyalar

### Backend
- **Python 3.12**
- **Django 5.2**
- **Django REST Framework 3.16**

### Authentication & Security
- **SimpleJWT**
- **PyJWT**
- Custom authentication backend

### Database
- **PostgreSQL 16**
- psycopg2-binary
- Database migrations & indexing

### Internationalization
- **django-modeltranslation**
- EN / UZ tillar qo‘llab-quvvatlanadi

### API Documentation
- **drf-spectacular**
- Swagger UI & ReDoc

### Media Handling
- **Pillow**
- Generic media model (image, video, file)

### Integrations
- **Telegram Bot API** — xatoliklar uchun alertlar

### DevOps
- **Docker**
- **Docker Compose**
- **Nginx**
- Alpine Linux

### Testing
- Django test framework
- Unit testlar
